# Colonel Horse Riding — Premium Equestrian Homepage

## Project Objective

Build a premium, cinematic and sophisticated homepage for **Colonel Horse Riding**, an equestrian/riding club.

The current phase is **ONLY the public-facing homepage/landing page**.

Do NOT build the customer dashboard, admin dashboard, slot booking system, horse marketplace, tack shop, café, guest house, therapy booking, memberships, horse leasing, horse auctions, donations, or other future functionality at this stage.

The homepage should establish the visual identity and premium positioning of Colonel Horse Riding while presenting the currently available horse-riding program clearly.

The website should feel like a **luxury private equestrian club / heritage stud farm**, not like a generic sports academy or ordinary horse-riding school.

# 32. MOTION PERFORMANCE

Animation must remain performant.

Requirements:

- Prefer transform and opacity
- Avoid expensive layout animations
- Use GPU-friendly properties
- Avoid unnecessary continuous animations
- Clean up GSAP ScrollTrigger instances when components unmount
- Respect `prefers-reduced-motion`
- Avoid excessive event listeners
- Avoid unnecessary re-renders

The website must remain smooth on mid-range mobile devices.

---

# 33. RESPONSIVE ANIMATION

Desktop and mobile should NOT necessarily use identical animations.

Desktop may include:

- Parallax
- Mouse movement
- Custom cursor
- More complex ScrollTrigger interactions

Mobile should use:

- Simpler reveals
- Fade
- Scale
- Short vertical transitions
- Touch-friendly interactions

Avoid expensive parallax and cursor effects on mobile.
